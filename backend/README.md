# bnr-backend

Bun + Hono backend for the Bank Licensing & Compliance Portal.

See `docs/architecture-thinking.html` and `docs/db-architecture.html` for the
design reasoning.

## Quick start

```bash
bun install
cp .env.example .env       # then edit DATABASE_URL / DATABASE_OWNER_URL
bun run db:migrate         # apply pre + drizzle + post migrations
bun run dev
```

Server defaults to `http://localhost:3001`.

## Local Postgres in 30 seconds

The schema relies on two Postgres roles by design (see
`docs/db-architecture.html` §3). The simplest local setup:

```bash
docker run --name bnr-pg \
  -e POSTGRES_USER=app_owner \
  -e POSTGRES_PASSWORD=app_owner_pw \
  -e POSTGRES_DB=bnr \
  -p 5432:5432 \
  -d postgres:16

# After the container is up, set app_user's password (the migration creates
# the role with NOLOGIN; we ALTER it here so it can connect).
docker exec -it bnr-pg psql -U app_owner -d bnr -c \
  "ALTER ROLE app_user WITH LOGIN PASSWORD 'app_user_pw';" \
  || echo "(run again after the first bun run db:migrate creates the role)"
```

Then in `.env`:

```
DATABASE_URL=postgres://app_user:app_user_pw@localhost:5432/bnr
DATABASE_OWNER_URL=postgres://app_owner:app_owner_pw@localhost:5432/bnr
```

The migration script will:

1. Create the `citext` and `pgcrypto` extensions (`migrations/sql/pre/`).
2. Apply Drizzle's generated DDL (`migrations/*.sql`).
3. Create the `app_user` role (idempotent), grant per-table privileges, and
   install the audit-log / terminal-state triggers (`migrations/sql/post/`).

A full Docker Compose for the whole stack will land in a later step.

## Scripts

| Script | What it does |
| --- | --- |
| `bun run dev` | Hot-reloading dev server. |
| `bun run start` | One-shot start. |
| `bun run typecheck` | `tsc --noEmit`. |
| `bun run test` | `bun test`. |
| `bun run db:generate` | `drizzle-kit generate` — diff `src/db/schema.ts` against the migrations folder and emit a new migration. |
| `bun run db:migrate` | Apply pre-DDL + Drizzle migrations + post-DDL. Idempotent. |
| `bun run db:studio` | Open `drizzle-kit studio` against the owner connection. |

## Layout

```
backend/
  src/
    env.ts                  Zod-parsed environment config
    db/
      schema.ts             Drizzle schema (six tables, three enums)
      index.ts              Runtime client (DATABASE_URL → app_user)
      migrate.ts            Migration runner (DATABASE_OWNER_URL → app_owner)
      audit-hash.ts         Hash-chain writer + canonical-payload helpers
    index.ts                Hono entrypoint
  migrations/
    0000_*.sql              Generated by drizzle-kit
    sql/
      pre/                  Run before drizzle (extensions)
      post/                 Run after drizzle (roles, grants, triggers)
  drizzle.config.ts
```
